Hospital Management System 🏥

📑Overview
The Hospital Management System is a web application built using ASP.NET Core MVC and Entity Framework Core. It enables Admins to manage patients, appointments, and scheduling, while Patients can register, book appointments, and view their appointment details.

🎯Features:

✅Admin Panel
  --> Manage patients, appointments, and doctor availability.
  --> Schedule appointments for patients.

✅Patient Panel
  --> Register, book appointments, and view upcoming appointments.

✅Appointment Management
  --> Admins can assign appointments and manage doctor schedules.

✅Notifications:
  --> In-app SweetAlert notifications for booking, canceling, or updating appointments.
  --> Email and SMS notifications to remind patients of upcoming appointments.
  
Technologies Used:
🔹 ASP.NET Core MVC (Backend)
🔹 Entity Framework Core (Database ORM)
🔹 SQL Server (Database)
🔹 Identity Framework (Authentication)
🔹 Bootstrap, SweetAlert, Chart.js (Frontend)
